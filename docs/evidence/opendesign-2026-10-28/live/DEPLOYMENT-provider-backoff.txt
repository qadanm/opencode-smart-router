What was added
--------------
OpenDesign's gateway runs pre-request checks (billing scope, then plan
entitlement) that were failing every few minutes during a sustained gateway
problem. Each failure had been charged to the serving model, which sidelined
healthy models and depressed their routing probability, while the router kept
sending the next prompt into the same broken path and the same wall.

Now: a provider-scoped fault counts toward a per-provider run of consecutive
failures with nothing succeeding in between.
  - Any successful request resets the run to zero. Blips that ride over on a
    retry never arm anything.
  - At five consecutive failures the whole provider is held back for three
    minutes, so routing can pick another provider instead of hammering a
    dead gateway.
  - If no other provider has allowance, the routing engine finds no eligible
    route and fails closed keeping the current model - the backoff can never
    block a prompt outright. This matters because the owner reported Go Plus
    and GOAT exhausted.

The membership-entitlement failure ("[code=internal_error] failed to evaluate
membership entitlement") is classified provider-scoped alongside the
billing-scope failure; it appeared live at 11:03:31 and was the last fault
still being charged to a model.
