What was wrong
--------------
The idle compaction deployed an hour earlier never fired. The host's
session.idle BUS EVENT carries sessionID, metadata and location - but no
outcome field. The outcome only exists on the persisted message record,
which the router never sees. The trigger required outcome === "succeeded",
which could never be true from the event.

Confirmed from the protocol schema: both session.idle event definitions list
sessionID/metadata/directory/workspaceID only. Zero occurrences of "outcome".

The fix
-------
Trigger on session.execution.succeeded (a turn finished cleanly) and on
session.idle (covers the rest). The ten-minute cooldown keeps them from both
firing. Compacting after a failed turn is still correct: the context is just
as large, and a smaller context makes the retry cheaper.

Interim relief
--------------

The session now fits OpenDesign's 328k window again, so the next prompt
